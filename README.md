# 贴纸工坊

贴纸工坊是一款浏览器里的复古剪贴画编辑器，可把图片与文字排成贴纸拼贴，并导出 PNG 成品。

## 能做什么

- 导入多张图片；可选择自动抠图，或直接保留原图。也支持拖放到画布和粘贴图片。
- 为图片贴纸生成白边、阴影与纸张质感，并可调整贴纸效果参数。
- 添加剪报字或手写气泡文字，编辑文字及纸张、文字颜色。
- 在画布上选择、拖动、缩放和旋转元素；通过图层面板调整前后顺序，并使用撤销/重做。
- 选择 16:9、9:16、1:1、3:2 或自定义画布尺寸；使用六种自动排版预设：主次群组、底部一排、对角线、散落拼贴、网格和环绕中心。
- 设置背景颜色与纸张颗粒；导出整张 PNG、单个贴纸 PNG，或复制整图到剪贴板。

## 界面与交互

工作区由顶部画布比例、缩放与历史操作区，左侧素材和排版工具，中间画布，以及右侧图层和属性面板组成。支持画布缩放、适应窗口、拖入图片、键盘撤销/重做；选中元素时会显示控制框与旋转柄。

## 技术实现

项目是原生 HTML、CSS 与 JavaScript ES modules 应用，使用 Canvas 2D 绘制编辑画布和导出图像。自动抠图通过 Web Worker 调用 Transformers.js 与 RMBG-1.4/ONNX；代码会尝试 WebGPU，并回退到 WASM CPU。仓库当前没有 package.json 或其他依赖清单，抠图引擎与模型按代码中的本地资源路径或远端 CDN/模型源加载。

## 本地运行

仓库没有构建脚本或包管理配置。可从项目根目录启动一个静态 HTTP 服务：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 `http://localhost:8000/`。通过 HTTP 服务访问是必要的：页面使用 JavaScript modules 和 Web Worker。首次使用自动抠图时，若本地没有相应引擎/模型资源，代码会尝试从远端来源加载；网络或模型加载失败时，界面提供原图导入的回退路径。也可选择“直接导入（不抠图）”。

## 导出与素材

导出功能提供整图 PNG、选中贴纸 PNG 和剪贴板复制。当前仓库未包含可引用的产品截图或演示素材，因此这里不附示意截图。
